# nurse-apri 応募準備ボード

nurse-apriを転職応募に向けて仕上げるための、日本語の個人用タスクボードです。

## 起動方法

`index.html`をブラウザーで開きます。ビルドや外部ライブラリのインストールは不要です。

## 主な機能

- 機能・品質・公開確認・応募準備の4カテゴリでタスクを管理
- 状況、優先度、カテゴリによる絞り込み
- 次の作業、今週の優先タスク、完了率、応募前チェックリストを表示
- タスクごとに学習メモ、次回作業、学習時間を記録
- 進捗はブラウザーのlocalStorageに保存。学習時間は空欄のまま保存可能

## 注意

タスクの初期状態は、作成時点で確認できた開発メモをもとにしています。実際に確認した後で状況を更新してください。データはブラウザーごとに保存され、別の端末とは同期しません。
